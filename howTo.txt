How to install it in Chrome

1.Open Chrome and go to chrome://extensions
2.Turn on Developer mode (top right toggle)
3.Click "Load unpacked"
4.Select your chat-bookmark-extension folder
5.Done! The extension icon will appear in your toolbar


How to use it
        Action             ShortcutSet                      Also
    Set Bookmark             Alt + B                    Popup Button
Jump back to bookmark        Alt + G                    Popup button
    Remove bookmark          Alt + R                 Click the PNG image
